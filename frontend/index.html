理论速查 —— 对话《卷积算子的等变性与拉氏函数》要点(变分/自伴/谱/能量语义)
① 变分可导出性 ⇔ 自伴(偶核) 卷积算子 A:u→k*u 平移等变。要让 δS/δu = A u, A 须为 L² 自伴 ⇔ 核偶函数 k(x)=k(−x) ⇔ 符号 ĥ(ω)∈ℝ。 此时二次泛函 S[u]=½∫u(k*u)dx 变分即得 A u。等变性给形状, 自伴性给可导出性。
② 设计空间层级 L1 所有卷积核(平移等变) → 加自伴 = L2 偶核(可导出拉氏量) → 加正定 ĥ≥0 = L3 凸能量(核方法/RKHS/协方差) → 加微分结构 = L4 格林核(有理/指数符号, 高阶拉氏量 S=½∫(|u|²+λ²|∇u|²)) → 加群作用 = L5 群等变核(旋转等)。每层 ⊆ 上层。
③ 一般核不能由多个拉氏量拼出 线性组合保持自伴 ⇒ 只能覆盖偶部。奇部 kₐ(反自伴)是陀螺项: ⟨u,Au⟩=0, 能量守恒但破时间反演; 复数化或辅助场/辛结构才能容纳(对话偏好: 保留实数、走耗散路线)。
④ 谱三分为势能 / 陀螺 / 耗散 自伴核按符号谱分解: H=H⁺+H⁻。A = A_pot + A_gyro − D: A_pot(符号 H⁺≥0)=势能/恢复力(来自拉氏量 S=½⟨u,A_pot u⟩); A_gyro(奇核)=陀螺, 能量守恒; D(正定偶核, 符号 −H⁻) 经 Rayleigh 耗散函数 R[v]=½⟨v, D*v⟩ 进入变分框架。
⑤ 能量判据(梯度流 ∂u/∂t = −A u, E=½‖u‖²) dE/dt = −⟨u, A u⟩: A 正定自伴 → 单调耗散; 负定自伴 → 增长(取负号成耗散); 反自伴 → dE/dt=0 相位旋转。探针面板逐个模式给出 ⟨u,Ku⟩ 与 S[u]=½⟨u,Ku⟩, 负值即“负能量模式”。
⑥ 示例: 十字核 [[0,1,0],[1,0,1],[0,1,0]] 偶核(D4 对称) ⇒ 可导出拉氏量; 符号 H=2cosω₁+2cosω₂ ∈ [−4,4] ⇒ 非正定/非凸; 且 K = Δ₄ + 4δ(离散拉普拉斯+中心冲激)。棋盘模式能量 S<0(对话最终分析的结论)。
